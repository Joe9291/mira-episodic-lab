# mira-episodic-lab

Public lab of the Mira experiment: can language-model agents, with free CPU compute only,
give a small open-weight language model functional episodic memory?

- `docs/PROTOCOL.md` - research protocol (criteria E1-E7, arms, controls, statistics)
- `episodic_lab/` - world generator, questions, evaluator, symbolic arm S0, runner
- `bench/m0/` - milestone 0 feasibility measurement on the GitHub runner
- `reviews/` - verbatim reviews by Gemini and Astra
- branch `results` - every run's receipts and outputs, including failures

Only code, synthetic worlds, results and reviews live here; no private material.
