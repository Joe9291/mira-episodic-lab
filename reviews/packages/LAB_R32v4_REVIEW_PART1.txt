# Round 3.2 - agent memory from S0 (design v4, after Astra's reviews of v1, v2 and v3)

Uncertainty removed: does an explicit episodic memory work as an agent memory (survives a
restart, answers from its own records, abstains correctly and only where it may), and
does a gain come from what is selected or from how it is processed? Ends with one run;
round 3.3 (action environment with causal interventions) starts from its result and is
prepared in parallel. Reviews: `reviews/2026-10-17_r32_astra.txt` (v1),
`reviews/2026-10-17_r32v2_astra.txt` (v2), `reviews/2026-10-17_r32v3_r33v2_astra.txt` (v3).

Basis: round 3.1/3.1b (docs/ROUND_3_1.md). Direct and instructed step-by-step answers of
both small readers fail at comparison, conjunctive matching with abstention, linking and
source filtering; extraction of a single detail works. Qwen3's whole thinking
configuration (thinking mode, its sampling and a 1024-token budget, changed together)
lifts all four, S5 to 20/21 (observed cases 6/7) - a reason for a limited later test,
not a reliability proof. The candidate procedure used did not remove the failures; it
does not prove that output format, scoring and calibration play no part.

## 1. Store (episodic_lab/memory.py)

Append-only JSON-lines file; one record per episode, written once and flushed; SHA-256
chain (changed, removed or reordered records are refused) plus an external seal (record
count and head hash kept outside the file) that also refuses a store whose last records
were cut off. Fields: identity (`id`, `stream`, `seq` = record time), `event_day`,
`actor`, `partner`, `action`, `object`, `place`, `source` (kind, by), original `text`,
`relations`, `encoder`. Derived state (latest place etc.) is computed at query time. The
runner's fingerprint uses a digest of the actual record contents, so any change of a
record in working memory while answering is detected.

## 2. Operators and scope

Every operator receives the records it may use and whether that set is the complete
store. Statuses: `ok`; `none_in_scope` and `no_observation` (only with a complete scope:
the cue's entities are known but the combination never occurred / an entity was never
recorded); `ambiguous`; `insufficient_evidence` (incomplete scope: no negative, no
"latest", no "last handler" may be concluded). Only `none_in_scope` maps to "none" in the
closed benchmark; everything that is not `ok` or `none_in_scope` answers "unknown". All
operators use the same semantics (compare_time included). Days that are not valid
integers (an encoder error) are treated as unknown, never compared.

Unknown values (v3, completed in v4). A field is unknown if the encoder declared it so
(record `extra.unknown`; its value is then None - every invalid or missing LM slot) or if
a field every episode has (actor, action, place, a valid integer day) is missing. A
missing partner or object without that declaration means "none in this episode". An
unknown value is never evidence of absence, order or uniqueness. `possible()` returns
the records that match a cue or could match it through an unknown field; a person could
be the actor or the partner of a record in which either is unknown. Rules, the same in
every operator: find - no exact hit but possible ones -> `insufficient_evidence`,
possible records with another value of the asked field -> `ambiguous`; latest / last
handler - every record that could be the latest one about the person or object (exact
records of the latest known day, exact undated records, and possible records that are
undated or not earlier) must agree (same place / same known actor), else `ambiguous`;
only possible records -> `insufficient_evidence`; state_at - possible records of that day
or undated ones block a negative and must agree on the place; compare_time - a second
exact OR possible match of a side makes it non-unique -> `ambiguous` (checked before the
negative for a missing side). A record whose known fields contradict the cue is no
possible match, and a possible record that cannot change the answer (earlier than the
latest known day, same place, same actor) does not block it. Every `ok` result carries a
non-empty string value. Tests: Astra's counterexamples (unknown actor later than the
latest record; unknown object of a later event by another actor; a second possible
comparison match), the cases in which the unknown cannot change the answer, and a
soundness test against brute force: for 400 random small stores with up to three unknown
fields, every answer other than "unknown" (full store, and certified struct3 selections)
equals the answer under EVERY completion of the unknown fields (exact semantics on the
completed records); the v3 operators fail this test in many cases, v4 in none (also in
10 x 1,500 stores outside the test suite).

On a partial (uncertified) selection, positive answers (find, comparison, state on a day)
are drawn from the selected records; a contradicting record outside the selection can
make them wrong. This is the declared cost of partial retrieval and is what lex3 and
random3 measure; negatives, latest and last handler are never concluded there.

## 3. Cells - reader and operators get the same selection, information and contract

| cell | selection | processing |
|---|---|---|
| lex3+reader / lex3+ops | BM25 over the raw texts, top 3; cannot certify completeness | LM reads the 3 notes / operators with incomplete scope |
| struct3+reader / struct3+ops | index scan over all records: all full matches of each event in the query first, best partial matches after; time-aware for "latest" (the person's most recent records), two-stage for E7 (the unique cue match, then its person's most recent records); certified complete when the full matches (or the latest-day records) fit into the 3 | LM reads the 3 notes / operators with the certified scope |
| full+ops (reference) | all records | operators, complete scope |
| random3+ops (control) | 3 records by a hash of the question | operators, incomplete scope |
| full+ops/lm-encoder | all records of a store written by the LM encoder | operators |

`covered` means: the selection is certified sufficient for THIS question (not that the
store is complete). struct3 certifies only if all full and possible matches of each
event fit into the budget, or, for latest and last handler, if every record that could be
the latest one (same rule as the operators, possible records included) is selected. A
test shows that the operators on a certified selection give exactly the full-store answer
(status and answer) for every query of the random stores above.
Within a pair, the reader receives in its prompt exactly what the operators use: the
coverage line (complete for this question / partial selection), and, when covered, the
index's entity knowledge (whether every name in the question occurs in memory); and it
follows the same contract: "none" only for a covered selection without the event and
with every name known, "unknown" otherwise (and for latest/last questions on a partial
selection). A test shows that an ideal reader following this contract gives exactly the
operators' answers in every row. The struct3 retriever contains processing of its own
(time order, two stages); this is part of the "struct" method and is reported as such. Baselines A0 and A1 (v1
instruction) run on the same worlds. Removed from round 3.2 (decision): the
thinking-reader cell (about 38 s per answer; a small targeted source test later is more
useful than a costly repeat of all criteria) and the `by_source` operator (the template
benchmark has no source items; source filtering returns with the action environment).

## 4. Per-answer record and evaluation

Every answer row stores, besides raw answer and category: the selected record ids, the
scope flag, the operator status and trace (replayed deterministically after the run from
the record set of that test point, never while answering) and, as evaluator-only
information, whether all gold target episodes were selected ("gold support"; not an
upper bound of accuracy). Cost per cell: LM calls, prompt and new tokens. A failing cell
is recorded with its traceback and does not stop the others.

Reported separately per cell: coverage share, accuracy on covered items, abstention
("unknown") and false recall on lures, gold support, cost (calls, prompt tokens, seconds),
and the development worlds (dev-m3) apart from the already used pilot worlds (pilot-m2).
Expected cost per world (both conditions): about 2 x [4 (Q1 + Qf) + 6 E] model calls
(four LM cells, six encoder questions per episode), roughly 1,400 calls and 1-2 hours on
the runner, well inside the 6-hour job limit.

The collector trusts nothing: it regenerates world and questions from series and index
(hashes must match, every expected item answered exactly once), re-scores every row from
its raw answer, recomputes all summaries, re-runs the deterministic cells and compares
their raw answers, recomputes every diagnostic field of every selecting cell (selection,
coverage, entity note, operator value, status, trace, gold support) from the store of the
matching test point, rebuilds the LM-encoder cell from its recorded records with its
original encoder name (so record identities are reproduced), re-derives the encoder's
reference from the regenerated episodes and its cleaned values and invalid flags from the
recorded raw replies (declared unknown slots included), recomputes the misbound control,
checks provenance (request and pins hashes, one code commit, and that it is the code
commit of the run, passed by the workflow) and the restart flags. The encoder adoption
decision (separate file ENCODER_DECISION: ADOPT / KEEP / UNDECIDABLE) is drawn only from
the complete, fully validated set of the 15 planned world reports; with a missing or
invalid report the verdict is INCOMPLETE, the decision UNDECIDABLE, and the tables of the
valid reports are marked as diagnostics only. "Accuracy covered" is pooled over all
covered final items of a series (not averaged per world first).

## 5. LM encoder

Slot filling by single-detail questions (day, first person, second person or none,
action, object, place), one fresh chat per slot, v1-style instruction; every value is
type-checked; an invalid or (for an always-present slot) missing value is listed in
`invalid`, stored as None and declared unknown in the record; the raw reply is kept; it
never stops the run. A reply for the second person that repeats the first person is read
as "no second person" (a declared normalisation; a wrong partner is then a slot error
measured by the partner slot accuracy, like any valid but wrong value). S1
qualified person, place, object and day; the second person and the action are measured
here for the first time. Adoption rule for round 3.3 (fixed now): all_slots (share of
episodes with every slot right) >= 0.95 AND the full+ops/lm-encoder cell within 0.02 of
full+ops on positive final items AND its lure false recall <= 0.05. "Positive final
items" = E2, E3a, E3b, E4, E7 of the final test, the two A/B orientations of an E3a pair
weighing 1/2 each, pooled over both conditions within a world, then the mean over all 15
worlds; lure false recall the same way. Lure correct rejection and "unknown" are reported
next to it (a low false recall alone is no rejection). These are technical decision
rules for development, not reliability claims. Otherwise the regex
encoder is used and the limit is stated. An adoption holds only for the round 3.2
template episode formats; other formats (the round 3.3 environment with "You" and
object-free events, free wordings) need their own check (round 3.4: frozen LM encoder on
held-out wordings).

## 6. Restart test (completion point)

Exactly the store file of the full+ops cell and its seal are handed to a fresh isolated
interpreter that receives only the store path, the seal, the fixed code and the public
questions. Passed if: (a) answers equal the in-process answers; (b) with an empty store
no positive item is answered correctly; (c) a store with its last record cut off and (d)
a store with one changed record are refused.

## 7. Worlds, model, run

Development series `dev-m3` worlds 0-9 and `pilot-m2` worlds 0-4 (paired with the pilot),
both overlap conditions, v1 question sets. Reader and LM encoder: qwen2.5-0.5b (selected;
no switch to Qwen3 without a measured reason: both pass S1). Expected on the template
benchmark: full+ops and struct3+ops near 1.0; the informative results are the reader vs
operator difference at equal selection, the lex vs struct difference, the LM encoder
and the restart test.

"""Round 3.2 comparison cells (docs/ROUND_3_2.md section 4) and the LM encoder.

All cells share the store (episodes appended once, in presentation order) and the
template question parser. Within one retrieval method, the reader cell and the operator
cell receive exactly the same selected records:

  lex3   BM25 over the raw texts, top 3. Cannot certify completeness (scope incomplete).
  struct3 an index scan over ALL records: per event in the query the records matching
         every cue feature (pattern completion fills up with the best partial matches);
         time-aware for "latest" (the person's most recent records) and two-stage for E7
         (the unique cue match, then its person's most recent records). Because the scan
         covered the whole store, a missing full match or a latest record is certified
         (scope complete for this query) as long as the full matches fit in the budget.
         This processing inside the retriever is part of the "struct" method.
  full   all records (the reference system, operators only).
  random3 3 records chosen by a hash of the question (control, operators only).

Readers get the selected notes as text; operators get the selected records and the scope
flag. Answering never changes a cell's state (runner fingerprint over the actual record
contents).
"""
from __future__ import annotations

import hashlib
import math
import re

from .arms import FORMAT_V1
from .memory import (FIELDS, EpisodeStore, Result, _day, _known, _minus, answer_query, could_be_latest,
                     encode_into, match, parse_question, possible, regex_encode)

K = 3
STYLE = "v1"
_WORD = re.compile(r"[a-z0-9]+")


def bm25_top(records: list[dict], query: str, k: int = K, k1: float = 1.5, b: float = 0.75) -> list[dict]:
    """Lexical retrieval over the raw episode texts; ties by record order."""
    docs = [_WORD.findall(r["text"].lower()) for r in records]
    if not docs:
        return []
    n, avg = len(docs), sum(map(len, docs)) / len(docs)
    terms = set(_WORD.findall(query.lower()))
    df = {t: sum(t in d for d in docs) for t in terms}
    scores = []
    for i, d in enumerate(docs):
        s = 0.0
        for t in terms:
            f = d.count(t)
            if f:
                idf = math.log(1 + (n - df[t] + 0.5) / (df[t] + 0.5))
                s += idf * f * (k1 + 1) / (f + k1 * (1 - b + b * len(d) / avg))
        scores.append((-s, i))
    return sorted((records[i] for _, i in sorted(scores)[:k]), key=lambda r: r["seq"])


def _overlap(record: dict, cue: dict) -> int:
    n = 0
    for key, value in cue.items():
        if key == "person":
            n += value in (record["actor"], record["partner"])
        elif key == "obj":
            n += record["object"] == value
        elif key == "day":
            n += _day(record) == value
        else:
            n += record[key] == value
    return n


def _best(records, cue, budget):
    """Full matches first, then records that could be full matches because a needed field
    is unknown, then the best partial matches. Certified only if all full and possible
    matches fit into the budget."""
    full = [r for r in records if _overlap(r, cue) == len(cue)]
    maybe = _minus(possible(records, **cue), full)
    taken = {r["id"] for r in full + maybe}
    partial = sorted((r for r in records if 0 < _overlap(r, cue) < len(cue) and r["id"] not in taken),
                     key=lambda r: (-_overlap(r, cue), r["seq"]))
    return (full + maybe + partial)[:budget], len(full) + len(maybe) <= budget


def _by_recency(rs):
    return sorted(rs, key=lambda r: (-(_day(r) if _day(r) is not None else 10 ** 9), r["seq"]))


def _recent(records, person, budget):
    """The records that could be the person's latest (memory.could_be_latest, including
    possible records with an unknown actor/partner) first, then the person's other dated
    records by recency. Certified if all records that could be the latest fit."""
    if not isinstance(person, str):
        return [], False
    mine = match(records, person=person)
    cands, _ = could_be_latest(mine, _minus(possible(records, person=person), mine))
    rest = _minus(_by_recency([r for r in mine if _day(r) is not None]), cands)
    return (_by_recency(cands) + rest)[:budget], len(cands) <= budget


def struct_select(records: list[dict], qtype: str, query: dict, k: int = K) -> tuple[list[dict], bool]:
    if qtype in ("object", "place", "person", "day"):
        got, ok = _best(records, query["cue"], k)
    elif qtype == "order":
        sides = [q for q in (query["a"], query["b"]) if q]
        got, ok = [], True
        for cue in sides:
            part, c = _best(records, cue, max(1, k // len(sides)) if sides else k)
            got += [r for r in part if r not in got]
            ok = ok and c
    elif qtype == "latest":
        got, ok = _recent(records, query["person"], k)
    elif qtype == "at_day":
        got, ok = _best(records, {"person": query["person"], "day": query["day"]}, k)
    elif qtype == "find":
        first, ok = _best(records, query["cue"], 1)
        full = [r for r in first if _overlap(r, query["cue"]) == len(query["cue"])]
        got = list(first)
        if full:
            more, c = _recent(records, full[0]["actor"], k - 1)
            got += [r for r in more if r not in got]
            ok = ok and c
    elif qtype == "act":
        # the record that could be the last event with the object (also one whose unknown
        # object could be it); certified only if there is at most one such record
        with_obj = match(records, obj=query["obj"])
        cands, _ = could_be_latest(with_obj, _minus(possible(records, obj=query["obj"]), with_obj))
        got = _by_recency(cands)[:1]
        ok = len(cands) <= 1
        if got:
            more, c = _recent(records, got[0]["actor"], k - 1)
            got += [r for r in more if r not in got]
            ok = ok and c
    else:
        got, ok = [], False
    return sorted(got, key=lambda r: r["seq"])[:k], ok


def _entities(qtype: str, query: dict) -> list[tuple[str, str]]:
    cues = [query["cue"]] if "cue" in query else [q for q in (query.get("a"), query.get("b")) if q]
    out = []
    for cue in cues:
        for key in ("person", "obj", "place"):
            if cue.get(key):
                out.append((key, cue[key]))
    if qtype in ("latest", "at_day"):
        out.append(("person", query["person"]))
    if qtype == "act":
        out.append(("obj", query["obj"]))
    return sorted(set(out))


def entity_note(qtype: str, query: dict, universe: list[dict]) -> str:
    """The index's knowledge about the question's names (the same knowledge the operators
    use to tell none_in_scope from no_observation)."""
    missing = [v for k, v in _entities(qtype, query) if not _known(universe, **{k: v})]
    if not missing:
        return "Every person, place and object named in the question occurs in memory."
    return "Never recorded in memory at all: " + ", ".join(missing) + "."


def reader_messages(question: str, notes: list[str], covered: bool, note: str | None,
                    answer_type: str) -> list[dict]:
    """Reader prompt with the SAME information and abstention contract as the operators:
    coverage of the selection for this question, the index's entity knowledge when the
    selection is covered, "none" only for a covered selection without the event and with
    every name known, "unknown" otherwise."""
    text = ("You answer one question from notes retrieved from your memory. Answer with only "
            f"{FORMAT_V1[answer_type]}, nothing else.")
    if answer_type == "choice":
        text += " If the notes do not settle it, answer with the single word: unknown."
    else:
        text += (" If the notes are complete for this question and none of them contains the event "
                 "asked about, answer with the single word: none - unless a name in the question was "
                 "never recorded in memory; then answer: unknown. If the notes are not complete and do "
                 "not settle the answer, or the question asks for the latest or last state and the notes "
                 "are not complete, answer with the single word: unknown.")
    coverage = ("Coverage: complete for this question (the whole memory was searched)." if covered
                else "Coverage: partial selection (other relevant notes may exist).")
    lines = [coverage] + ([note] if covered and note else [])
    body = "\n".join(notes) if notes else "(no notes)"
    user = "\n".join(lines) + f"\n\nMemory notes:\n{body}\n\nQuestion: {question}"
    return [{"role": "system", "content": text}, {"role": "user", "content": user}]


class _Cell:
    DIGEST_COVERS = ("store", "model", "encoder")
    EXPOSURE = None
    E1B = {"internal_replays": 0, "optimizer_steps": 0, "store_writes": 1}
    READER = False

    def __init__(self, model=None, store: EpisodeStore | None = None, encoder=regex_encode,
                 encoder_name: str = "regex"):
        if self.READER and model is None:
            raise ValueError("reader cells need a model")
        self.model = model if self.READER else None
        self.store = store if store is not None else EpisodeStore()
        self.encoder = encoder
        self.encoder_name = encoder_name

    def encode(self, text: str) -> None:
        encode_into(self.store, text, self.encoder, self.encoder_name)

    def state_digest(self) -> str:
        models = [m for m in (self.model, getattr(self.encoder, "model", None)) if m is not None]
        return self.store.content_digest() + "".join(m.weights_digest() for m in models)

    def select(self, text: str, qtype: str, query: dict, records: list[dict]) -> tuple[list[dict], bool]:
        raise NotImplementedError

    def explain(self, text: str, records: list[dict]) -> dict:
        """Deterministic replay of the selection (and the operator result) for one question
        over a given record set; used by the evaluator after the run, never while answering."""
        parsed = parse_question(text)
        if parsed is None:
            return {"selected": [], "covered": False, "entity_note": None, "result": None}
        got, covered = self.select(text, *parsed, records)
        out = {"selected": [r["id"] for r in got], "covered": covered,
               "entity_note": entity_note(*parsed, records) if covered else None, "result": None}
        if not self.READER:
            out["result"] = self._ops(got, parsed, covered, records).to_json()
        return out

    def _ops(self, got, parsed, covered, records):
        # `covered`: the selection is certified sufficient for THIS question (an index scan
        # over the whole store); the index then also knows which names occur at all
        return answer_query(got, *parsed, complete=covered, universe=records if covered else None)

    def reader_prompt(self, text: str, answer_type: str, records: list[dict]) -> list[dict]:
        parsed = parse_question(text)
        got, covered = self.select(text, *parsed, records)
        note = entity_note(*parsed, records) if covered else None
        return reader_messages(text, [r["text"] for r in got], covered, note, answer_type)

    def answer(self, text: str, answer_type: str) -> str:
        parsed = parse_question(text)
        if parsed is None:
            return "unknown"
        records = self.store._records
        if not self.READER:
            got, covered = self.select(text, *parsed, records)
            return self._ops(got, parsed, covered, records).answer()
        return self.model.generate(self.reader_prompt(text, answer_type, records))

    NAME, READER = "lex3+reader", True

        return bm25_top(records, text), False


class Lex3Ops(Lex3Reader):
    NAME, READER = "lex3+ops", False


class Struct3Reader(_Cell):
    NAME, READER = "struct3+reader", True

    def select(self, text, qtype, query, records):

class Struct3Ops(Struct3Reader):

class FullOps(_Cell):

def _clean(raw: str, kind: str):
    text = raw.strip().split("\n", 1)[0].strip().strip(".").strip()
    low = text.lower()
    if low in ("none", "nobody", "no one", "nothing"):
        return None
    if kind == "day":
        m = re.fullmatch(r"(?:day\s*)?(\d+)", low)
        return int(m.group(1)) if m else INVALID
    if kind == "object" and low.startswith("the "):
        text = text[4:]
    if kind == "place" and low.startswith("at "):
        text = text[3:]
    if kind == "action" and low == "hidden":  # the one irregular participle of the templates
        text = "hid"
    return text


INVALID = object()
_NAME_SHAPE = {"person": re.compile(r"[A-Z][a-z]+ [A-Z][a-z]+"), "place": re.compile(r"[A-Z][a-z]+ [A-Z][a-z]+"),
               "object": re.compile(r"[a-z]+ [a-z]+"), "action": re.compile(r"[a-z]+")}


class LMEncoder:
    """Slot filling by single-detail questions. S1 qualified person, place, object and day;
    the second person and the action are measured here for the first time. Every slot is
    type-checked: an invalid or missing required value (no day number, a reply not shaped
    like a name, "none" for a slot every episode has) is listed in `invalid`, stored as
    None and declared unknown in the record; the raw reply is kept in `raw`. It never stops
    the run. A reply for the second person that repeats the first person is read as "no
    second person" (a declared normalisation, measured by the partner slot accuracy)."""

    def __init__(self, model):
        self.model = model
        self.raw: list[dict] = []       # telemetry per encoded episode, not memory
        self.invalid: list[list] = []   # invalid slots per encoded episode

    def __call__(self, text: str) -> dict:
        raw = {}
        for slot, (question, kind) in SLOT_QUESTIONS.items():
            msgs = [{"role": "system", "content": "You read one note and answer one question "
                     f"about it. Answer with only {SLOT_FORMAT[kind]}, nothing else."},
                    {"role": "user", "content": f"Note:\n{text}\n\nQuestion: {question}"}]
            raw[slot] = self.model.generate(msgs)
        content, bad = postprocess(raw)
        self.raw.append(raw)
        self.invalid.append(bad)
        return content, bad


def postprocess(raw: dict) -> tuple[dict, list]:
    """Raw slot replies -> (record content, invalid slots); every invalid slot is None in
    the content and declared unknown in the record. Deterministic, so the collector can
    re-derive both from the recorded raw replies."""
    out, bad = {}, []
    for slot, (_, kind) in SLOT_QUESTIONS.items():
        value = _clean(raw[slot], kind)
        if value is INVALID:
            bad.append(slot)
            value = None
        elif value is not None and kind in _NAME_SHAPE and not _NAME_SHAPE[kind].fullmatch(value):
            bad.append(slot)
            value = None  # the raw reply stays in the encoder's raw record
        out[slot] = value
    for slot in ("actor", "action", "object", "place", "event_day"):  # required in every episode
        if out[slot] is None:
            bad.append(slot)
    if out["partner"] == out["actor"]:
        out["partner"] = None
    return {k: out[k] for k in FIELDS}, sorted(set(bad))


def diagnose(cell, rows: list[dict], world: dict, questions: dict) -> None:
    """Per answer row: deterministic replay of the selection, coverage, entity note and
    operator result on the record set of that test point, plus evaluator-only gold support.
    Used by the job after the run and by the collector to recompute every field."""
    texts = {e["episode_id"]: e["text"] for e in world["episodes"]}
    by_qid = {q["qid"]: q["text"] for q in questions["public"]["final"]}
    n_early = sum(e["block"] == "early" for e in world["episodes"])
    for row in rows:
        recs = cell.store._records if row["phase"] == "final" else [r for r in cell.store._records
                                                                      if r["seq"] < n_early]
        diag = cell.explain(by_qid[row["qid"]], recs)
        chosen = {r["text"] for r in recs if r["id"] in set(diag["selected"])}
        targets = questions["gold"][row["qid"]]["targets"]
        diag["gold_support_selected"] = all(texts[t] in chosen for t in targets) if targets else None
        row["diag"] = diag


def slot_accuracy(pairs: list[tuple[dict, dict]]) -> dict:
    """pairs: (lm record content, regex truth) -> share correct per slot and all slots."""
    acc = {s: sum(a[s] == t[s] for a, t in pairs) / len(pairs) for s in FIELDS}
    acc["all_slots"] = sum(all(a[s] == t[s] for s in FIELDS) for a, t in pairs) / len(pairs)
    return acc
