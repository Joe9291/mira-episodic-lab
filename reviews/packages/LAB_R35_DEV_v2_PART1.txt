YOUR POINTS AND WHAT WAS DONE
B1, first point (action used before its own decision): decisions now run in a fixed order action, actor, receiver, object, place, day. The action is decided first with its real rule (margin, threshold, tie -> unknown). The narrator constraint ("a person seen is never the narrator") is applied only if the action was ACCEPTED as "was". With an unknown action no action-dependent constraint applies, so the roles of every other possible action stay available. The action-independent constraint (receiver differs from actor) stays.
B1, second point (margins hidden by filtering): actor and receiver margins are now computed over all feasible role pairs - per actor value the best joint score actor + receiver over its feasible receivers, margins between these values; likewise per receiver value. Equally good best pairs therefore give margin 0 for each component in which they differ (unknown); a shared component stays decided.
B1, same procedure: one function decides a slot (slot_view / decide_slot) for both calibration and application. Calibration runs slot by slot in the decision order; a later slot sees the earlier slots decided with THEIR calibrated thresholds - exactly what decide_record does with the frozen thresholds.
B2 (your note): calibration now reports a basis per slot - "multi" (multi-value cases exist), "single_only" (only single-value cases), "none" (no evaluable case). STRUCTURAL requires "single_only" AND >= 200 single values AND their precision >= 0.99 (I added this evidence bar, the same as for a threshold; it is a tightening - please confirm or reject). "none" gives no threshold (slot always unknown).
C: recomputed offline on the recorded p8 encodings of run 39186450732 (no model calls), see results. The frozen configuration now also names the decoder version (d2) and the SHA-256 of the eight round 3.5 code files; the collector reports any mismatch with the running code as INCOMPLETE (ENCODER_QUALIFIED = UNDECIDABLE), so code drift after the freeze cannot pass unnoticed.
Your ideas, all done: (1) schema-constrained controls with the same candidates, decoder and thresholds; (2) the two regression tests (plus three more); (3) structural uniqueness by origin ("text" = the note's candidates had one value, "schema" = one value left by the role constraints); (4) freeze documentation (decoder version, thresholds, changed role of the calibration split).
