# Strategy after the first pilot (2026-10-17)

Two independent analyses, written blind: `reviews/2026-10-17_strategy_claude.md` (sealed
before Astra's answer) and `reviews/2026-10-17_strategy_astra.txt`. This file is the
synthesis; where the two differ, the decision and its reason are stated.

## 1. What the pilot supports (both agree)

- With exactly its evidence the reader answers recall, state and day items almost
  perfectly (Qwen2.5 O1). This does NOT show that it stored, found or kept anything.
- Selection among similar episodes, combination of evidence, temporal comparison in the
  A/B format and rejection of binding lures fail (A1 E2 0.29; lure false recall 0.99 for
  Qwen2.5 in A1 and O1; E3a pair score 0 even with both dated episodes present).
- S0 (explicit event table) solves every item: the tasks are solvable by explicit event
  storage with fitting operations. Nothing here requires a neural mechanism.
- Better answers and fewer false claims do not come together automatically (Qwen3: O1 E2
  up, O1 lure false recall up).
- Five worlds are development information (5/5 passes give a one-sided 95% lower bound of
  about 0.55 for new worlds).

## 2. Thinking errors (combined)

1. **"Episodic memory or database" is a false dichotomy** (Astra; Claude's draft used
   it). A database is an implementation; episodic functions describe what is kept from
   single experiences and how it is used. No behavioural test can exclude a sufficiently
   general database. The claim we can earn is "an externally implemented functional
   episodic agent memory"; a parametric mechanism is a separate, additional claim;
   human autonoetic re-experiencing is not decided by our tests.
2. **Three goals were mixed**: (a) a working episodic agent memory, (b) episodic storage
   in weights, (c) human-like re-experiencing. **Decision: goal (a) first** (fastest,
   testable); (b) later as its own research question with a precise hypothesis; (c) not
   claimed.
3. **A3 was not defined as different from S0.** A new name is not a new research object.
   **Decision:** no second store; S0 evolves into the agent memory, and the report states
   which functions are added.
4. **Weak readers decided architecture questions.** A channel that answers "A" to two
   dated events cannot judge a memory. Binding, comparison and abstention must be measured
   per sub-skill and, where the reader fails, done by explicit operators.
5. **The template benchmark carried too much.** It is solvable by a regex parser and
   tests only known question families. It stays as a controlled diagnostic, not as the
   basis of the success claim.
6. **Weak baseline**: the pilot gate compares with A0, which has no information and
   scores 0 by construction. Gains are measured against A1, lexical retrieval and S0.
7. **Free generation of tiny models measures format and position bias.** A second,
   registered output channel scores candidate answers (with swapped positions and an
   abstention option).
8. **Definition gaps**: the episodes are a narrated third-person world, not the agent's
   own experience; E4 asks for a day, while source monitoring means observed / done /
   told / inferred; E5 is closed-world ("not stored" is not "never happened"); E6 can
   mix retrieval difficulty with information loss; unanticipated later use, corrections
   and knowledge states, transfer to new forms, and the stage at which an error arises
   (encoding, retrieval, reasoning, output/abstention, action) are not measured.
9. **Process**: too much assurance of the test bench before the system's benefit was
   visible; reviews per fix instead of per decision; two AI reviewers share blind spots,
   so independently derived test cases and a few examples checked by Joe add more than
   further matching approvals; the assistants (Claude, Astra) are not the system under
   study, which needs its own verifiable memory boundary.

## 3. Plan (finite rounds, each with the uncertainty it removes and its stop rule)

**Milestone 3 goal (Astra's definition, adopted):** an agent keeps a single experience
across a process restart, uses it for a goal announced later, and targeted interventions
on exactly that memory change its actual decision.

**Round 3.1 - diagnostic battery** (removes: which sub-skills the reader can carry).
Qwen2.5-0.5B and Qwen3-0.6B only. About 20 short cases each for five sub-skills: (1) take
one detail from a present episode, (2) compare two dated events, (3) tell a full
combination from partial matches, (4) link two present episodes via a person or object,
(5) tell an observation from someone's claim from missing information. Positive and
negative cases matched in number of notes and length. Two registered output channels:
free text (current grammar) and candidate scoring (log-likelihood over the allowed values
plus abstention, positions swapped). Cases generated by code with independently
checkable answers. Stop rule: a sub-skill below 95% (development target, not a
confirmatory threshold) is solved by an explicit operator in the prototype; no further
prompt variants without a stated purpose.

**Round 3.2 - agent memory (S0 evolved)** (removes: does the explicit memory work as an
agent memory, and does the gain come from retrieval or from reasoning). Append-only
episodes with: random id and stream; record time separate from event time; participants,
action, object, place and other observed features; source (own action, observation,
report by someone, inference); original input; relations (corrections, linked events,
derived states). A current-state view may update; history is never overwritten.
Operations: multi-cue search, temporal comparison, state at a time, latest state,
linking via shared people/objects; every answer returns the episode ids and the
operation trace. Negative results are three-valued: no matching event in a fully
observed scope / no observation / several matches with different answers (only the first
maps to "none" in the closed benchmark). 2x2 crossing with shared question parsing:
lexical vs structured retrieval x LM reader vs explicit operators. Completion point: the
memory survives a process restart (chat history discarded; only the declared memory and
fixed software); the same test without it loses the episode-dependent performance.
Expected on the template benchmark: near 100% (a working prototype, not a surprise).

**Round 3.3 - text action environment with causal memory tests** (removes: does memory
change behaviour causally). About 6 places, 8 objects, 2 other actors; the agent can go,
observe, receive a message, move or use an object; observations and own actions are
stored as episodes; the goal is announced only after the experiences. Paired worlds are
identical at decision time except one earlier experience, which makes a different action
correct (example: which of two later indistinguishable keys opens a door, assigned at
random per world). Interventions: intact memory, no memory, random episodes of equal
size, swapped relevant binding with features kept, relevant episode removed, irrelevant
episode removed. Scored by the environment outcome; text answer and action success are
recorded separately. Expected pattern for a positive result: intact succeeds; removing
the relevant episode hurts this decision; a swapped binding changes the decision in the
predicted direction; removing irrelevant episodes matters much less.

**Round 3.4 - extensions, one at a time**: more distractors; recurring people and
objects; reports by others and later corrections (source monitoring, knowledge states);
new wordings with LM extraction (the template parser must fail there); new combinations
of known operations; unexpected later questions about incidentally recorded details;
longer histories with a bounded retrieval budget.

**Later**: P1 only with a precise hypothesis (single observed bindings stored by a few
declared adapter updates, retrievable after restart without episode text or external
store, with update controls, old/new episode tests, new wordings, general-ability checks;
a lower loss is not enough). C1 only after a measured problem of the working memory
(retrieval cost, fixed storage budget) with a checkable optimisation goal.

## 4. What we will call the result

"Functional episodic agent memory (externally implemented)" when it shows, for the agent's
own experiences: experience reference; bound event traces (people, content, time, place,
source); flexible retrieval from different cues including unanticipated ones; historical
states and knowledge states despite later changes; source monitoring; behavioural benefit
where the current observation is not enough; causal dependence under targeted
interventions; transfer and honest uncertainty. Not claimed: human autonoetic
re-experiencing; not claimed without separate proof: storage in weights.

## 5. Process changes

- Reviews per decision and per finished round, not per fix; small fixes after Claude's
  own check, listed in the next review package.
- Each round states the uncertainty it removes and when it ends.
- Independent validation: a handful of concrete cases per round checked by Joe (optional,
  a few minutes), and test cases derived independently of the system's code.
- The pilot worlds (series pilot-m2) are spent for development; the confirmatory series
  starts only after the relevant adaptations, on a signed seed.
